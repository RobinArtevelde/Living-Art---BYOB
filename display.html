Je opende dit bestand rechtstreeks (of via Live Server). Het project moet via Vite draaien:

  1. Open een terminal in de projectmap byob-schilderij
  2. Typ npm install (alleen de eerste keer)
  3. Typ npm run dev
  4. Open het adres dat verschijnt, bv. http://localhost:5173/display.html
